# GUOCR：截图识字

按快捷键截图、识别文字或翻译，结果自动复制到剪贴板。操作方式参照 QQ 截图。

- **离线识别**：用 RapidOCR（PP-OCRv6 模型，onnxruntime 推理），模型随包分发，不用 API Key
- **翻译不依赖 Google**：内置离线大模型 Qwen2.5-3B（llama.cpp Vulkan 版推理）。自动使用电脑上的显卡（NVIDIA / AMD / Intel 都支持，无需安装 CUDA），每段约 0.3～0.5 秒；没有可用显卡时自动改用 CPU（每段约 2～3 秒）。默认有网用 Google，没网自动用离线；也可在设置里选「仅离线」
- **版面分析**：能正确处理 Word 并排两页、同页多栏——左页（栏）读完再读右页；自动识别段落（段间距、首行缩进、段尾短行、编号列表），段内折行合并，中文不加空格、英文去掉断词连字符；中英文分句（能识别 Mr. / e.g. / 3.14 这类缩写和小数）
- **QQ 式截图**：冻结屏幕后框选；鼠标悬停会自动高亮下面的窗口，单击即可识别整个窗口；带放大镜和取色信息
- **三个功能、三个快捷键**：截图（复制图片）、识别文字、图片翻译（把译文贴回截图上原文的位置，原文/译文/译文图片都能单独复制）
- **翻译语境（预设）**：托盘右键 →「翻译语境…」，用自然语言告诉本地大模型这次翻译的语境、某个词在此语境下的含义或译法、其他要求（输入长度不限，可随时补充或要求删改）；模型会复述它记住了什么，词义表也可以直接编辑。可存多套预设，选一套作为当前。设了预设后翻译优先用本地大模型（Google 在线翻译无法接收语境说明）。保存在 `%APPDATA%\GUOCR\presets.json`
- **截图可直接粘贴成文件**：在资源管理器的文件夹里 `Ctrl+V` 会生成一个 PNG 文件；粘贴到 QQ、微信、Word 等程序里仍然是图片
- **自动复制**：识别完直接写入剪贴板，可马上 `Ctrl+V`；结果窗口不抢焦点，也可以在里面改完再复制
- 支持多显示器和不同缩放比例（按物理像素裁剪）
- 常驻系统托盘，快捷键可改，可设开机自启

## 使用

| 操作 | 说明 |
| --- | --- |
| `Alt+Q`（默认） | 截图：框选后把**图片**复制到剪贴板（在文件夹里粘贴会得到 `截图_日期_时间.png`） |
| `Alt+E`（默认） | 识别文字：框选后把**文字**复制到剪贴板（单击托盘图标也可以） |
| `Alt+R`（默认） | 翻译：识别后把译文**贴回截图**上原文的位置（保留原来的背景色和文字颜色）。弹窗里显示译文图片、原文、译文，各自可复制，图片还能另存为。剪贴板里同时放着译文图片和译文文字：粘贴到聊天窗口或文件夹得到图片，粘贴到文本框得到文字 |
| 拖动鼠标 | 框选区域，松开后立即处理 |
| 单击 | 识别当前高亮的窗口 |
| `Enter` | 识别当前高亮的窗口 |
| 方向键 | 光标逐像素微调 |
| `Esc` / 右键 | 退出截图 |

识别完成后，文字已经在剪贴板里了。结果窗口按 `Esc` 或「关闭」隐藏，下次截图时也会自动隐藏。

托盘图标右键菜单里的「设置」可以改这些：

- 三个功能的快捷键：每个快捷键旁边会实时显示「✓ 可用」「✗ 已被其他程序占用」或「✗ 与某功能重复」；有冲突时无法保存；留空表示不启用该功能
- 是否弹出结果窗口（关掉后只显示托盘气泡）
- 是否保留屏幕上的原始换行（默认不保留：按段落输出，一段一行，自动处理分栏/分页）
- 开机自动启动（写入 `HKCU\...\Run`）

配置文件在 `%APPDATA%\GUOCR\config.json`，日志在 `%APPDATA%\GUOCR\guocr.log`。

## 运行

需要 Python 3.10 及以上版本。

```bat
run.bat
```

第一次运行会自动创建 `.venv` 并安装依赖，之后以无控制台模式在后台启动。也可以手动运行：

```bat
.venv\Scripts\python.exe main.py
```

## 打包成 exe

有三种版本，都会在最后自动运行一次 `GUOCR.exe --selftest`。它不弹界面，只检查识别、离线翻译和 Word 联动组件，结果写入 `%APPDATA%\GUOCR\guocr.log`。

| 脚本 | 产物 | 大小 | 说明 |
| --- | --- | --- | --- |
| `build_slim.bat` | `dist_slim\GUOCR.exe` | 约 150 MB | **精简版，适合发布到 GitHub Release**。不内置离线翻译模型；识别和在线翻译开箱即用，离线翻译模型（约 2 GB）在首次需要时自动下载到 `%LOCALAPPDATA%\GUOCR\models`，只下载一次 |
| `build_onefile.bat` | `dist_onefile\GUOCR.exe` | 约 2.2 GB | 完整版，一个文件包含全部模型，完全离线，拷到任何 64 位 Windows 10/11 上双击即可运行 |
| `build.bat` | `dist\GUOCR\` 文件夹 | 约 2.4 GB | 文件夹版，启动最快，分发时要复制整个文件夹 |

单文件版每次启动要先解压到临时目录，所以启动会慢一些（完整版约 20～30 秒，精简版约 5 秒）。配置和日志都在 `%APPDATA%\GUOCR`。

打包前会自动下载离线翻译需要的文件到 `models\`（只下载一次，不进入 git 仓库）：

- llama.cpp b11617 Vulkan 版推理程序
- Qwen2.5-3B-Instruct（Q4_K_M 量化）
- OPUS-MT 英中小模型（兜底用）

### 第三方组件与许可

| 组件 | 用途 | 许可 |
| --- | --- | --- |
| [RapidOCR](https://github.com/RapidAI/RapidOCR)（PP-OCRv6 模型） | 文字识别 | Apache-2.0 |
| [onnxruntime-directml](https://github.com/microsoft/onnxruntime) | 识别推理（显卡/CPU） | MIT |
| [PySide6](https://doc.qt.io/qtforpython/) | 界面 | LGPL-3.0 |
| [llama.cpp](https://github.com/ggml-org/llama.cpp) | 离线大模型推理（Vulkan） | MIT |
| [Qwen2.5-3B-Instruct](https://huggingface.co/Qwen/Qwen2.5-3B-Instruct) | 离线翻译 | Qwen Research License：**仅限非商业用途** |
| [OPUS-MT en-zh](https://github.com/Helsinki-NLP/Opus-MT)（Argos Translate 打包） | 离线翻译兜底 | CC-BY-4.0 |
| [CTranslate2](https://github.com/OpenNMT/CTranslate2) | 兜底模型推理 | MIT |

在线翻译使用 Google 翻译的免费网页接口，不是官方 API，可能随时变化或被限流，届时会自动改用离线翻译。

## 已知限制

- **快捷键冲突**：启动时如果有快捷键被其他程序占用，托盘会弹出提示，请在设置里换一个。
- **翻译引擎**（设置里可选）：
  - 在线优先（默认）：先用 Google 翻译免费接口，识别出的文字会发给 Google；连不上时自动改用离线模型，并在 10 分钟内不再尝试在线，避免每次都卡在超时上
  - 仅离线：完全不联网，速度快（约 0.1～0.5 秒）；质量比 Google 略差，个别短词可能直译生硬，常见界面词（确定、取消、了解更多等）用内置词表兜底
  - 仅在线：只用 Google
- 翻译方向：英文、日文等外文 → 简体中文。识别模型本身支持中、英、日文（含假名）；日文翻译用 Google 或本地大模型，兜底的小模型只会英译中，遇到日文会原样保留。
- **竖排日文**：自动识别竖排（列从右往左、列内从上往下），按竖排规则分段（列顶缩进、列底提前结束）；竖排的列逐字摆正后再识别（标点、长音“ー”、小写假名不再丢失）；译文也按竖排贴回原位。竖排中横躺的西文字母暂不支持。
- **图片翻译按段落重排**：每段整段送去翻译（保留完整句意），译文在原段落区域内重新排版（保留首行缩进、背景色和文字颜色），放不下时自动缩小字号。
- **管理员权限窗口**：如果前台是以管理员身份运行的程序（例如部分游戏），截图遮罩可能拿不到键盘焦点，此时 `Esc` 无效，用**右键**退出即可。若要完全正常，也可以用管理员身份运行本程序。
- **独占全屏的游戏或视频**：通过 GDI 截屏可能得到黑屏，这是系统限制。
- **识别速度**：有显卡时用 DirectML（NVIDIA/AMD/Intel 均可），整页约 0.6 秒、小选区约 0.2 秒；没有显卡时用 CPU，整页约 2～3 秒。
- **截 Word 窗口**：按截图位置精确定位到是哪个 Word 文档窗口（支持多个 Word 程序、多份文档并排），直接读取原文校正识别结果；框选区域部分被其他窗口挡住时，被挡部分的文字可能缺失。

## 项目结构

```
main.py               入口（也是 PyInstaller 的打包入口）
guocr/app.py          托盘程序主体：热键 → 截图 → OCR → 剪贴板
guocr/overlay.py      全屏截图遮罩（框选、窗口吸附、放大镜）
guocr/ocr.py          RapidOCR 封装（显卡/CPU 自动选择）、页面检测、编辑标记清理、后台识别线程
guocr/layout.py       版面分析：分栏/分页（XY-cut）→ 行 → 段落 → 句子
guocr/translate.py    翻译：Google 在线接口 → 离线大模型（llama.cpp）→ OPUS-MT 兜底，自动降级；离线模型按需下载
guocr/wordlink.py     截 Word 窗口时直接读取原文（按窗口句柄定位文档、与识别结果逐词对齐）
guocr/terms.py        专业词库（计算机/机械/生物/数学 + 用户自定义）
guocr/context.py      翻译语境预设：本地大模型理解用户的自然语言说明并复述、词义增删
guocr/contextdlg.py   翻译语境对话框
guocr/glossary/       内置领域词库
guocr/pin.py          译文贴图窗口（覆盖在原位）
guocr/imaging.py      图片翻译（把译文贴回截图）、图片写入剪贴板（含可粘贴为文件的格式）
guocr/hotkey.py       Win32 RegisterHotKey 全局热键
guocr/winutil.py      窗口枚举、单实例、开机自启、前台激活
guocr/result.py       识别结果窗口
guocr/settings.py     设置对话框
guocr/config.py       配置读写
guocr/icon.py         运行时绘制的程序图标（也用于生成 .ico）
```
